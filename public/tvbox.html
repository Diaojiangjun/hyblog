关于TVBox配置生成器的使用说明和技术解答

TVBox配置生成器是什么？

这是一个免费的在线工具，用于快速生成 TVBox 所需的 JSON 配置文件。

  • 添加视频源（Sites）
  • 添加直播源（Lives）
  • 配置解析接口（Parses）
  • 一键导出 JSON 和 Base64

生成后的配置如何使用？

  1. 在本页完成配置
  2. 点击“下载 tvbox.json”
  3. 上传到可访问地址
  4. 在 TVBox 中填入配置地址并重启

视频源（Sites）如何填写？

填写源名称和完整 API 地址，例如 https://example.com/api.php/provide/vod，并按需开启可搜索/快速搜索/可筛选。

直播源（Lives）支持哪些格式？

支持 M3U 与 TXT。TXT 格式为 频道名,播放地址。可选填写 EPG 地址显示节目单。

Base64 编码怎么用？

点击“Base64编码”可得到编码字符串，格式为 8位随机字符**Base64内容，可直接作为 TVBox 配置地址使用。
